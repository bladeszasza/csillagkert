# Csillagkert

Játékos, magyar nyelvű tanuló- és fejlesztőjáték óvodás korúaknak iPadre és Apple Pencilre.
Feladatok → csillagok → jutalomjáték. Hibázásért nincs büntetés.

**Játék:** https://bladeszasza.github.io/csillagkert/

Nincs build lépés: sima HTML + ES modulok + three.js (`vendor/`). GitHub Pages-en fut.

Helyi kipróbálás: bármilyen statikus kiszolgálóval, pl. `node serve.cjs . 8080`.
